# Urban-Nav-SR

This repository contains the SR navigation stack split into:

- `Policy_part/`: NavFlow/ViNT policy runners, ONNX inference, realtime trajectory overlay, and offline visualization tools.
- `Agent_part/`: route server and visual prompt tools.
- `Locomotion_part/`: robot-side locomotion, viobot, GNSS/odom integration, and ROS utilities.
