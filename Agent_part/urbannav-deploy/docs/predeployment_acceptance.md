## 未通过的模型质量项

服务的 ready 表示可接收推理请求，不表示允许机器人运动。
已有记录说明原生r10本身在本clip的42个历史test窗口有ADE4.79m、FDE8.57m。
此次55对匹配中51对有完整四秒参考；34对非零年龄窗口fresh/dual平均点位误差4.47/4.72m。
两个历史集合窗口不同，不能直接以均值证明部署无回归；旧视觉缓存混杂也限制query年龄的单因果结论。

最小初始动作诊断只复用一个已保存条件。标准正态seed0/1较零初始动作降低XY误差，但增加yaw误差，并在参考前进时产生早期负向位移。
这不足以改变生产采样策略，不选择最佳seed作为上线版本。

| 待定验收条件 | 应固定的定义 | 当前缺口 |
| --- | --- | --- |
| 四秒轨迹位置质量 | 同一32点时间网格的平均点位误差、末点误差；按直行/转弯/停车分层 | 允许阈值与分层覆盖量未约定 |
| 朝向质量 | 绕回后的绝对yaw误差；平均及尾部统计 | 容差未约定，不能用XY改善抵消yaw退化 |
| query保留影响 | 同一当前观测、相同视觉策略和初始动作，比较fresh与保留query | 固定视觉策略后的分层质量证据不足 |
| 停车与近障碍行为 | 停车漂移、错误移动、轨迹有效范围；真实shadow只输出候选控制 | 历史42条is_stop均为0，不能证明停车能力 |
| 实际时限 | 分开统计query更新、新轨迹、控制循环和过期比例 | Orin未测；真实采集链路未接入 |

用户尚未指定质量阈值或既有验收标准，不能自行把有限输出/单例改善标为导航通过。
本clip已用于诊断，后续模型或采样选择须用独立验证数据，并保留测试使用记录。
