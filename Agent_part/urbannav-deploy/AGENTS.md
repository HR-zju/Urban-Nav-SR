# 部署模块开发边界

用户仅授权开发 Urban-Nav-SR/Agent_part；本目录是 Urban-Nav-SR 父仓统一管理的部署模块。
修改限定在本目录，保持共享 Policy_part 和其他人的代码不变。
本目录不创建独立 .git 或 submodule。提交在 Urban-Nav-SR 父仓执行，仅暂存本目录内本轮授权的改动。
只实现当前需要的最简代码，保留模型输入输出合同，异常直接报告，使用已有维护环境。
测试只覆盖新增或改变的路径，复用既有原生推理证据，禁止重复运行旧模型测试。
Orin 连接仍暂停；shadow 只记录候选计划，不创建运动发布器。
提交和 push 根据用户明确指令执行。
